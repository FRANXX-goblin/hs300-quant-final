本目录已包含除PPT以外的全部材料：

- 书面技术报告（Word，29页，可直接另存为PDF）；

## 一、必须先替换的信息

打开根目录 `config.py`，替换以下内容：

```python
MEMBERS = [
    {"name": "成员一", "sid": "学号1", "role": "因子构建与数据清洗"},
    {"name": "成员二", "sid": "学号2", "role": "回测实现与模型优化"},
    {"name": "成员三", "sid": "学号3", "role": "收益归因与风险分析"},
    {"name": "成员四", "sid": "学号4", "role": "产品材料与报告撰写"},
]
GITHUB_LINK = "https://github.com/yourname/hs300-quant-final"
XUEQIU_LINK = "https://xueqiu.com/P/YOUR_PORTFOLIO"
```

另外，报告封面课程名称目前为“《量化投资》课程期末项目”，如课程名称不同，请在
`src/report_docx.py` 搜索“课程期末项目”并修改。

替换后重新生成报告：

```bash
python scripts/run_all.py
```

报告位置：`output/report/沪深300低风险增强多因子策略_技术报告.docx`。

## 二、GitHub 代码上传

1. 在 GitHub 新建仓库，例如 `hs300-quant-final`，设为 Public。
2. 在项目根目录执行：

```bash
git init
git add .
git commit -m "HS300 low-risk enhanced multi-factor strategy"
git branch -M main
git remote add origin https://github.com/你的用户名/hs300-quant-final.git
git push -u origin main
```

注意：`.gitignore` 已排除 `data/cache/` 与 `output/`，避免上传约80MB行情缓存和报告文件。
仓库中保留了约12KB的历史成分股文件、行业分类文件和全部源代码，复现者运行
`python scripts/update_data.py` 即可重新下载数据。

3. 将仓库链接填入 `config.py` 的 `GITHUB_LINK`，重新生成报告封面。

## 三、雪球模拟组合

1. 登录雪球网（xueqiu.com），进入“模拟组合”→“创建组合”。
2. 组合名称：`沪深300低风险增强一号`；组合类型：公开；基准：沪深300。
3. 打开 `output/live/xueqiu_portfolio.md`，按其中30只股票等权买入（每只约3.33%）。
   最新信号日为2026-10-30，建议建仓日为2026-11-02。若实际建仓日晚于该日期，
   可先按名单建仓，并在报告中说明实际建仓日期。
4. 每月最后一个交易日收盘后运行：

```bash
python scripts/live_signal.py
```

按新的 `output/live/holdings_latest.csv` 在下一交易日调仓。
5. 将组合链接填入 `config.py` 的 `XUEQIU_LINK`，重新生成报告封面。

雪球组合需要实际运行一段时间才有跟踪记录。建议在报告中说明“模拟盘自2026年11月
起跑”，并把样本外回测（2026年1—11月）与模拟盘实际跟踪分开表述。

## 六、报告的核心结论（答辩/路演可用）

1. 低波动与低换手因子在2018—2025年全样本IC为正（0.049、0.056），t值约2.0—2.3，
   方向与经济含义一致。
2. 研究模型相对基准模型年化收益提高5.15个百分点，最大回撤从-34.74%降至-26.54%，
   改善主要来自风险调整后收益，而非收益弹性。
3. 策略是防御型风格：2018、2021—2024年取得正超额，2019—2020年成长牛市和2025年
   大盘上涨阶段跑输。不能包装成“全天候alpha”。
4. 收益归因显示，线性因子溢价贡献为负，超额主要来自综合得分顶端的选股效应与行业配置；
   金融行业平均主动权重超过30%，产品化时加入“单一行业≤10只”约束，年化收益降至6.52%，
   但行业分布更均衡。
5. 容量：10%调仓参与率约束下约1.5亿元；放宽至20%约3亿元，适合中小规模私募产品。
6. 费率：管理费1.0%+托管费0.2%+超额10%业绩报酬，费后年化约5.15%，费后超额约1.56%。

## 七、复现常见问题

- **首次运行很慢**：需要下载约550只股票，约15—30分钟；已有缓存会跳过。
- **个别股票下载失败**：程序会跳过，不影响整体结果；可在日志中查看失败代码。
- **baostock登录失败**：本项目主数据源已改为akshare；baostock仅用于读取历史成分股文件
  （文件已随仓库提供），不影响运行。
- **报告中文字体**：需要Windows自带“宋体”“黑体”“Microsoft YaHei”；如缺失，
  可在 `src/report_docx.py` 与 `src/charts.py` 中替换字体名称。
- **PDF转换**：用Microsoft Word打开docx，另存为PDF即可；页数和版式不变。
