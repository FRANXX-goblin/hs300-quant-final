# 沪深300低风险增强多因子策略

本仓库是一个可复现的 A 股多因子选股研究项目。策略以沪深300历史成分股为股票池，在价值（EP、BP）与规模（小市值）基准模型上，加入 20 日低波动与 20 日低换手两个因子，构建月度调仓、等权持有 30 只股票的防御型多头组合，并与沪深300全收益指数（H00300）对比。

## 核心结果（2018-02 至 2025-12）

| 组合 | 年化收益 | 年化波动 | 夏普 | 最大回撤 | 年化超额 | 信息比率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 基准模型（价值+规模） | 2.30% | 18.97% | 0.016 | -34.74% | -1.28% | -0.112 |
| 研究模型（+低波+低换手） | 7.46% | 16.86% | 0.324 | -26.54% | 3.87% | 0.255 |
| 产品实施版（行业≤10只） | 6.52% | 17.15% | 0.263 | -26.64% | 2.93% | 0.194 |
| 沪深300全收益 | 3.59% | 19.48% | 0.081 | -41.56% | — | — |

2026 年 1—11 月样本外：研究模型年化 0.34%，沪深300全收益约 -10.1%，年化超额约 12.5%。

> 重要结论：策略是防御型风格，弱市与震荡市超额明显，2019—2020 年成长牛市和 2025 年大盘上涨阶段跑输基准。因子溢价在统计上并不显著，超额主要来自综合得分顶端的选股效应与行业配置，不宜包装成“全天候 alpha”。

## 安装

```bash
pip install -r requirements.txt
```

## 数据

仓库不包含约 80MB 的行情缓存。首次运行前执行：

```bash
python scripts/update_data.py
```

该脚本会：

1. 读取 `data/constituents_history.parquet` 中的历史成分股，并获取当前沪深300成分股；
2. 通过 akshare 下载个股后复权日线（新浪财经）与估值数据（东方财富）；
3. 下载沪深300全收益指数 H00300；
4. 将结果写入 `data/cache/`。

首次下载约 550 只股票，耗时约 15—30 分钟（视网络情况）。脚本支持断点续传：已存在的缓存会被跳过。

数据来源与口径：

- 个股日线：新浪财经，后复权；收益率由日线涨跌幅计算。
- 估值：东方财富，PE(TTM)、PB(MRQ)、流通市值。
- 历史成分股：baostock `query_hs300_stocks`，按每个调仓日查询。
- 基准：中证指数公司沪深300全收益指数 H00300。

## 复现

```bash
python scripts/run_all.py
```

输出：

- `output/tables/`：IC、回测、归因、风险、容量、费率、敏感性等 CSV；
- `output/figures/`：净值、回撤、IC、分组、归因、容量等 PNG；
- `output/live/`：最新一期模拟盘持仓。

## 最新模拟盘信号

```bash
python scripts/live_signal.py
```

脚本读取最后一个完整月末信号（默认 2026-10-30），按研究模型打分并施加“单一行业≤10只”约束，输出 30 只等权持仓到 `output/live/holdings_latest.csv`，同时生成组合持仓说明 `output/live/xueqiu_portfolio.md`。

## 回测设置

- 样本：2018-01-31 至 2025-12-31，共 95 个调仓期；2017 年用于因子历史窗口。
- 调仓：每月最后一个交易日收盘生成信号，下一交易日收盘调仓。
- 持仓：综合得分前 30 名，等权，满仓，不做空、不加杠杆。
- 成本：单边 0.10%，按单边换手率计算，买卖双边均收费。
- 基准：沪深300全收益指数（H00300）。
- 样本划分：2018—2021 训练期，2022—2025 验证期，2026 样本外模拟。

## 主要文件说明

- `src/factors.py`：因子定义与月度面板构建。所有因子仅使用调仓日及以前的数据。
- `src/backtest.py`：日频净值循环，调仓日按目标权重成交并扣费。
- `src/attribution.py`：Fama-MacBeth 横截面回归与组合收益分解。
- `src/risk.py`：容量估算、费率情景、压力区间。
- `scripts/live_signal.py`：按最新信号生成下一期持仓名单。
